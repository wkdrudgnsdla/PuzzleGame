# 실제 플레이 캠페인

구성 기준은 [기믹 중심 스테이지 구성하기](codex://threads/01a17c62-d20b-7553-bcb4-1ac1dd46bcce)에서 정리한 **주 기믹 도입 → 변형 → 익숙한 보조 기믹과 조합 → 종합**이다. 스테이지마다 주 기믹을 정하고, 관찰 위치·장치 조합·전력 전달을 통해 판단할 내용을 늘린다. 허용 오차를 줄이거나 발판 수만 늘리는 방식으로 난이도를 올리지 않는다.

배치 원본 데이터는 My project/Assets/_Game/Editor/CampaignStageCatalog.cs다. 별도 튜토리얼 한 개와 실제 게임플레이 스테이지 열다섯 개를 정의한다. **기믹 블록 사이에 이동용 다리나 중간 발판을 만들지 않는다.** 시점을 조정해 목적 블록의 바닥과 현재 블록의 바닥을 화면에서 직접 이어 이동한다. 다른 레일이나 열쇠를 먼저 완료할 필요 없이 도착한 장치를 바로 해결할 수 있다. 실제 전원이 필요한 회로에는 레일·열쇠가 전원을 켜는 연결이나 앞 전원에서 받은 충전 상태만 사용한다.

모든 기믹은 현재 발판이나 체크포인트와 무관하게 2D에서도 표시한다. 전선은 원격에서도 접합과 전원 상태가 맞으면 충전되므로 B 발판에 착지하지 않고 A→B 다음 B→C 각도를 맞출 수 있다. 레일은 몸으로 밀고 열쇠는 접촉해서 획득한다. 캠페인의 독립 군집을 여러 방향으로 수십 미터씩 떨어뜨리고, 단일 장치 맵의 깊이 간격도 넓혔다. 시작 25°/25°와 각 기믹의 대표 해법 시점에서는 서로 다른 장치의 투영 영역이 겹치지 않는지 검사한다. 모든 각도에서의 겹침을 금지하는 규칙은 아니다.

우측 미니맵은 북쪽(+Z)이 위인 실제 XZ 배치를 고정해서 보여준다. 착지 블록과 현재 지지 발판, 플레이어·카메라 방향, 열쇠·레일·전선·전구·출구 상태를 표시한다. 2D 이동 중에는 실제 3D 복귀 후보 위치를 파란 표식으로 보여준다. 미니맵은 입력을 가로채지 않으며 아래 설명 패널은 추가하지 않는다.

Unity에서 **Puzzle Game > Play Campaign > 00 Tutorial**을 연다. 01~15 메뉴로 원하는 스테이지를 직접 열 수 있으며, 실제 플레이에서는 클리어 후 Enter로 다음 씬에 이동한다. 빌드 시작 씬은 Tutorial_CoreMechanics이고 이후 실제 1~15가 순서대로 등록된다. 예전 실험 맵은 별도 폴더에 남겨 두고 빌드에서는 비활성화한다.

공통 UI는 `Assets/_Game/Prefabs/UI/ProjectionHUD.prefab`을 사용한다. 상단은 모드·각도·`클리어 조건 (완료/전체)`만 표시하며, 완료 개수는 RequiredForExit가 켜진 기믹 기준이다. 한 전력 네트워크에 필수 전구가 여러 개 있으면 모두 켜졌을 때 해당 기믹 한 개가 완료된다. 모든 필수 기믹을 완료하면 진행도 글씨가 초록색으로 바뀐다. 복귀 체크포인트는 이 개수에 포함하지 않는다. 왼쪽 아래 조작표와 우측 미니맵도 같은 프리팹에 포함한다.

## 난이도 구성

- 1~3은 열쇠의 공통 원리를 익히고, 3스테이지에서 사이드 획득과 탑뷰 평면 획득을 구별한다.
- 4~6은 몸으로 미는 레일을 소개한 뒤 여러 접합부와 탑뷰에서 꺾이는 레일을 더한다.
- 7~9는 전력의 이동과 저장을 소개하고, 익숙한 레일을 초기 전원 공급 수단으로 사용한다.
- 10~12는 주 기믹이 계속 중심이 되도록 두 종류 이상을 조합하고, 전력 분기의 충전 순서와 사이드·탑뷰 선택을 추가한다.
- 13~15는 서로 다른 장치의 관찰 시점과 실제 전원 공급 관계를 종합한다.

12·15의 전력 분기는 하나의 켜진 출발 전원이 서로 다른 두 수신부로 갈라지는 구조다. 어느 쪽을 먼저 충전할지 선택할 수 있으며, 두 출력 모두 필수 완료 대상이다. 분기 충전 여부가 블록 간 이동이나 다른 레일의 작동을 막지 않는다.

## 유지할 플레이 규칙

- 기믹 블록 사이에 이동용 다리·계단·중간 발판을 배치하지 않는다. 별도의 이동 시점에서 두 블록의 바닥을 직접 이어 건넌다.
- 방마다 거리·높이·방향을 별도 좌표로 지정한다. 사이드 레일 해법에서는 다른 블록이 플레이어 몸통을 가리지 않아야 하고, 탑뷰 레일은 윗면 위에서 스위치와 접촉하며 평면으로 밀 수 있어야 한다.
- 상하 각도의 절댓값이 40도 이상이면 탑뷰 2D가 된다. 튜토리얼·3·6·12·15의 대표 탑뷰 해법은 55도이며, WASD 평면 이동과 중력 없는 조작을 사용한다.
- 레일과 열쇠에는 다른 기믹의 완료 여부를 요구하는 일반 선행 조건을 부여하지 않는다.
- 전력 구간은 위에서 아래로 배치하며, 충전된 상태는 시점을 바꾼 뒤에도 유지된다.
- 레일이나 열쇠가 전원을 켜도록 구성한 회로는 해당 전원이 실제로 켜져야 충전된다.
- 체크포인트 표식 접촉을 기믹 활성화 조건으로 요구하지 않는다.
- 출구는 모든 필수 기믹을 완료하면 활성화된다. 실제 클리어는 3D 출구 장소에 도착해야 한다.
- 일반 스테이지에는 설명 패널이나 블록 위 문구를 추가하지 않는다. 간단한 조작 설명은 별도 튜토리얼에서만 제공한다.
- 전선·레일의 절단면과 연결 구간은 블록 밖의 노출된 위치에 배치해, 블록 뒤에 숨겨진 연결을 정답으로 사용하지 않는다.
- 허용 오차는 난이도 증가 수단으로 사용하지 않는다. 후반부의 차이는 장치 조합·관찰 위치·전력 전달에 있다.

캠페인 데이터의 RequiresRoom은 **전력 구간의 출발 전원을 켜는 장치**만 가리킨다. 레일이나 열쇠의 사용 순서를 제한하지 않는다. SuppliesPower는 다음 전력 구간의 초기 전원을 공급하는 장치를 나타낸다. Drop은 양수로 기록되지만 실제 전력 출력 착지대는 그만큼 아래에 놓인다. Key와 Rail의 Pitch는 정답 시점의 기울기로, 기존 사이드 구간은 0도이고 대표 탑뷰 구간은 55도다. 전력 정답의 pitch는 출력 낙차와 깊이의 비율로 결정된다.

연속된 전력 구간은 앞 구간의 수신 전원을 다음 구간의 출발 전원으로 재사용한다. 세 구간 레일은 첫 접합부를 지난 위치를 유지하고, 3D로 돌아가 시점을 바꿔 다음 접합부를 이어갈 수 있다. 클리어에는 모든 필수 장치의 완료와 실제 출구 도착이 필요하다.

배치 생성기는 접합점과 짧은 접합 구간의 원본 3D 가림을 검사한다. 모든 레일은 각 접합 해법 시점에서 스위치 뒤에 서는 위치부터 선로 끝까지 플레이어 몸통 영역이 다른 투영 블록과 겹치지 않아야 한다. 방·전원·출구 사이는 별도 시점에서 바닥 경계가 이어지고, 다른 블록에 머리가 막히지 않는 직접 이동 경로가 있어야 한다. 앞에서 내려다보는 시점과 뒤에서 올려다보는 시점을 모두 고려한다. 저장 씬 검사도 레일 몸통 공간과 중간 다리 부재를 다시 확인한다. 런타임도 가림 조건으로 연결을 거부하므로, 보이지 않는 접합면을 2D 그림만 덮어 연결하지 않는다.

목적 블록까지 한 번에 이어지지 않아도 기존 열쇠 블록·레일 블록·전력원 블록을 경유할 수 있다. 검사는 새 이동 발판을 추가하지 않고 기존 기믹 블록만으로 이루어진 연결 그래프에서 도달 가능성을 확인한다. 각 이동에는 좌표 전환 시의 몸통 공간과 실제 점프 높이를 적용하며, 검사에 사용한 경유 순서가 게임의 고정 이동 순서가 되지는 않는다.

SourceOffset은 방의 명시적인 3D 좌표이고, ExitOffset은 마지막 장치의 도착 블록에 대한 출구의 3D 변위다. 앞 전원을 재사용하는 연속 전력 구간은 이전 수신 블록을 공유한다. RailDepths와 RailJointYawOffsets는 각 레일 접합부의 거리와 시점을 개별 지정한다. RailPlanarAngles는 각 구간의 수평면 진행 방향으로, 튜토리얼은 두 번째 구간을 90도 꺾어 D에서 W로 미는 방향을 바꾸고, 6스테이지는 70도 대각선으로 응용한다. PowerSpan·BranchYawOffset·BranchDepthOffset·BranchDropOffset은 전력원 간 거리와 분기의 공간 배치를 지정한다. 공통 간격이나 공통 하강량으로 방을 자동 배치하지 않는다.

이 문서는 스테이지 설계와 제작 데이터를 설명한다. 플레이 검증·게임 난이도 검증을 완료했다는 의미는 아니며, 요청에 따라 실제 플레이 검증은 사용자가 진행한다.
