# 기믹 스테이지

Unity **Puzzle Game > Mechanic Stages**에서 6~9번 씬을 연다. 씬은 Assets/_Game/Scenes/Mechanics/에 저장되어 있다. 기존 1~5번 도전 스테이지는 변경하지 않는다.

| 스테이지 | 진행 |
|---|---|
| 06 Split Key | 열쇠 정렬 → 2D에서 획득 → 3D 출구 |
| 07 Rail Switch | 독립된 두 층을 차원 전환으로 오가며 두 레일을 원하는 순서로 해결 → 정상 출구 |
| 08 Power Relay | 위층 A → 아래 B → 아래 C 전구 → 맨 아래 출구 |
| 09 Rail + Power Relay | 위층 레일로 A 활성화 → A→B→C→D로 내려오며 충전 → 맨 아래 출구 |

## 조작과 활성화

- 3D에서 우클릭 드래그로 카메라를 조절하고 R로 2D에 들어간다. WASD는 플레이어 이동, 좌클릭 드래그는 화면 이동, 마우스 휠은 확대·축소다. 화면 이동과 확대·축소는 3D·2D에서 모두 사용한다. 카메라는 플레이어를 따라가며, 회전 중에도 이동·점프할 수 있다.
- **기믹이 있는 발판을 밟지 않아도 모든 기믹이 보이고 동작한다. 체크포인트를 누르거나 먼저 통과할 필요가 없다.**
- 레일은 2D에서 초록 스위치에 몸을 접촉하고 A/D로 밀어 노란 도착점으로 옮긴다. 레일 간 완료 순서는 강제하지 않으며, 연결되지 않은 접합부에서는 멈춘다.
- 전선은 어느 발판에서든 두 절단면이 이어지는 시점을 맞추고 2D에 들어가면 자동으로 충전된다. 착지·현재 발판 ID·체크포인트를 요구하지 않는다. 각 구간의 높이차에 맞춰 상하 각도도 조절한다.
- 기본 위치 허용 오차는 투영 좌표 0.4 유닛, 방향 오차는 15도다. 카메라 각도의 허용 범위는 조각 사이 깊이에 따라 달라진다.
- 레일·전선·전원·열쇠는 3D와 2D에서 모두 표시한다. 발판이 바뀌거나 아직 연결하지 않은 기믹도 숨기지 않는다. 레일 밀기와 열쇠 획득에는 몸의 접촉이 필요하다.
- 하단 설명 패널과 블록·전원 장치의 월드 글씨는 사용하지 않는다.

## 체크포인트와 클리어

7~9번의 체크포인트는 **복귀 위치를 자동 저장하는 용도**다. 지정된 발판 어디에든 3D로 착지하면 저장된다. 표식에 다가가거나 클릭할 필요가 없고, 이전 체크포인트를 건너뛰어도 다음 실제 착지대를 저장할 수 있다. 기믹 활성화나 출구 해금의 조건으로 사용하지 않는다.

기믹 완료 후 3D 출구에 도착하면 클리어된다. 전선 스테이지는 최종 전구 점등이 출구 해금 조건이다. 체크포인트 완료를 추가로 요구하지 않는다. 잠긴 출구는 회색, 해금 후에는 연두색이다.

낙하하면 저장된 발판으로 돌아오며 열쇠·레일·충전 진행은 유지된다. 리스폰할 때 카메라 각도·화면 이동 구도·확대·축소 상태도 유지된다. Backspace는 기믹과 카메라를 포함한 전체 초기화다.

## 배치와 동선

| 스테이지 | 발판 윗면 높이 |
|---|---|
| 07 | 레일 I 0 → 레일 II 2.75 → 출구 6.05 |
| 08 | A 9.9 → B 6.6 → C 2.75 → 출구 0 |
| 09 | 레일 15.4 → A 12.65 → B 8.8 → C 6.05 → D 2.75 → 출구 0 |

7번은 레일 두 구역을 다른 높이와 방향으로 배치했다. 각 블록 사이를 차원 전환으로 오가며 어느 레일부터 해결해도 된다.

8·9번 전선 구간은 위에서 아래로 진행한다. 전원은 각 발판에 놓인 실제 배터리·전구이며, 케이블도 각 발판의 표면에 고정되어 있다. 다음 블록과 출구는 시점을 맞추고 차원 전환으로 이동한다. 9번은 위층 레일 완료로 A 전원을 켜며, 전력 전달에 필요한 실제 충전 관계는 유지된다.

독립된 조작 블록 사이에 보조 다리를 두지 않는다. 각 구간의 크기·높이차·간격은 해당 기믹과 차원 전환 동선에 맞춰 다르게 구성한다.

## 전력 상태

파란 창은 충전된 전원, 노란 창은 비어 있는 전원이다. 연결된 2D 전선에 파란 에너지가 출발점부터 도착점까지 차오르며, 기본 충전 시간은 2.5초다. 끝까지 도달하면 도착 전원이 파란색으로 바뀐다.

충전된 전원은 3D 전환과 시점 변경 후에도 유지된다. A→B를 충전한 뒤 B 발판으로 이동해 각도를 바꾸고 B→C를 이어갈 수 있다. 모든 전선을 동시에 연결할 필요는 없다. 미완성 충전은 연결을 끊거나 3D로 나가면 일시 정지하고 재연결 시 이어진다. 다른 블록으로 이동해도 이미 연결한 전선과 양쪽 전원은 계속 보인다. 각도를 바꿔 접합이 떨어지면 두 전선 반쪽과 저장된 충전 길이를 표시하며, 접합이 다시 맞아야 충전이 이어진다.

## 편집

- Map / Platforms 아래 구간 그룹에 착지 블록과 전원·전선 경로 점이 함께 있다. Play를 끈 상태에서 수정한다.
- 전원 기준점은 각 발판 위 0.5, 케이블 중심은 각 발판 위 0.24, 레일 점은 각 발판 위 0.9 높이다. 전선 절단면은 발판 바깥으로 빼서 블록에 가려지지 않도록 한다.
- 레일·전선의 OperatingPlatforms는 배치 정보이며 표시·조작·충전을 제한하지 않는다. 레일 조작은 스위치와 몸의 실제 접촉으로 판정한다. 체크포인트 조건은 없다.
- ProjectionWire.SourcePath는 출발 전원→절단면, TargetPath는 반대 절단면→도착 전원 순서다. 각 배열에는 두 점 이상이 필요하다.
- 전원의 StartsPowered는 초기 충전 여부, IsFinal은 최종 전구 여부다. Label은 Inspector와 코드용 이름이며 화면에 글씨로 표시하지 않는다.
- StageRoute.CheckpointPlatforms는 각 복귀 표식에 해당하는 실제 발판이다. 7~9는 RequireCompletionForExit가 꺼져 있다. 기존 1~5의 순서형 클리어 조건은 유지된다.
- 블록 사이 이동용 보조 다리는 배치하지 않는다. 기믹 완료는 출구 해금과 실제 전원 공급에 반영한다.

**Puzzle Game > Connection Layout Tool**은 선택한 접합점 두 개를 정답 시점에서 겹치도록 깊이 방향으로 배치한다. Undo와 Scene 뷰 미리보기를 지원한다. 선택한 접합점만 움직이므로 나머지 경로 점은 별도로 조정한다.

6번 생성 코드는 Editor/MechanicStageAuthoring.cs, 7~9번 구성은 Editor/LayeredMechanicStageAuthoring.cs와 LayeredRailStageLayout.cs에 있다. **Create Missing Scenes**는 없는 씬만 만들며 기존 편집 내용을 덮어쓰지 않는다.

요청에 따라 플레이·자동 테스트는 실행하지 않았다. 씬 생성에 필요한 Unity 가져오기·컴파일만 수행한다.
